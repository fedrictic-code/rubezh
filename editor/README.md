# Редактор «Рубежа» (Windows)

Скачать: раздел Releases → «editor-latest» → `RubezhEditor-windows.zip`. Распакуйте и запустите `rubezh_editor.exe`.

Рабочая папка редактора: `Документы\RubezhEditor\assets\mod` — это копия `flutter/assets/mod` из репозитория.
Кнопка «Готово» отправляет изменённые файлы в репозиторий одним коммитом, ждёт сборку APK и сохраняет его в «Загрузки».
